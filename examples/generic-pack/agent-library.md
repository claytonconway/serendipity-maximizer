# Agent Library — Generic Example Pack

This is a **worked example content pack** for a fictional company so the framework runs out of the box. Replace this with your own domain-specific pack.

**Example company:** *Meridian Robotics* — a fictional pre-seed startup building autonomous warehouse robots. Used here purely to demonstrate the pack format.

Each agent has: a domain lens, serendipity targets, a primary discovery type, the roles it suits, and stage relevance. Copy this structure for your own agents.

---

## Agent 01 — Hardware Physics Bridge
**Tag:** Physics | **Primary type:** B | **Token tier:** Medium

**Domain lens**
- Mechanical actuation, drivetrain efficiency, sensor fusion
- Battery chemistry and power management physics
- Cross-domain analogs: insect locomotion, swarm behavior in nature
- Materials science for lightweight structural components

**Serendipity targets**
- Type B bridges: biological locomotion → robot mobility
- Power efficiency gains from adjacent industries (EV, drones)
- Structural weight reduction without stiffness loss

**Best for roles:** CTO, Head of Engineering, Program Manager
**Stage relevance:** All stages

## How to build your own pack

1. Copy this file's structure
2. Replace each agent's domain lens with your industry's actual knowledge areas
3. Keep the metadata fields (tag, primary type, token tier, roles, stage relevance) — the framework reads them
4. Adjust the number of agents (the framework selects 5 per session from whatever roster you define)
5. Pair with a matching `role-stage-matrix.md`
