# Visualizations

The framework supports two optional visual tools. They render whatever content pack you load, so they aren't checked in here as static files — they're generated from your pack.

## Role × Stage Explorer
An interactive matrix: pick a role and stage, see which 5 agents activate and why. Ask Claude: *"Generate the role-stage explorer for my content pack as an HTML artifact."*

## Architecture Diagram
A system diagram showing your agents fanning out to the convergence synthesizer and calibration engine. Ask Claude: *"Generate the architecture diagram for my content pack."*

Both render directly in Claude as artifacts. Because they're pack-specific, regenerate them whenever your agent roster changes.
